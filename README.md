# 🌐 Proyecto Web Full Stack con Docker

Este proyecto es una aplicación web desarrollada bajo una arquitectura **Full Stack**, que integra:

- 🖥️ Frontend
- ⚙️ Backend
- 🗄️ Base de Datos
- 🐳 Contenedores con Docker

---

## 📌 Descripción

La aplicación permite gestionar usuarios, productos o cualquier entidad del negocio según el caso.  
Está diseñada siguiendo buenas prácticas de desarrollo, separación de responsabilidades y despliegue mediante contenedores Docker.

---

## 🧱 Tecnologías utilizadas

### Frontend
- HTML
- CSS
- JavaScript
- Framework: React / Vue / Angular

### Backend
- Node.js / Python / Java
- Framework: Express / Django / Spring Boot

### Base de Datos
- PostgreSQL / MySQL / MongoDB

### DevOps
- Docker
- Docker Compose
